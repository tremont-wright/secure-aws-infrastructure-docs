# Secure AWS Architecture — Cloud Engineering Portfolio

This repository contains a cloud architecture design document demonstrating the design, security, operation, and lifecycle management of a private AWS environment.

The goal of this project is to showcase practical cloud engineering thinking — including networking, identity, security, observability, operational lifecycle, risk management, and cost awareness — at a production-ready level.

---

## Contents

- **secure-aws-architecture-mid.pdf**  
  A mid-level cloud engineer design document describing:
  - Requirements and constraints
  - Architecture and design decisions
  - Networking and connectivity model
  - Identity and access controls
  - Security controls and threat considerations
  - Observability and auditability
  - Operational lifecycle and cost management
  - Risks, mitigations, and outcomes

---

## Key Focus Areas

- Security-first design
- Identity-based access (IAM + Systems Manager)
- Private networking with controlled egress
- Centralized logging and auditability
- Infrastructure treated as reproducible and disposable
- Tradeoffs between security, cost, and operational complexity
